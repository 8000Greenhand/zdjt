# Temu 前台截图助手 v0.1

这个仓库先做第一版：**把截图、标题命名、保存这条核心链路跑通**。

当前版本不是全自动爬虫，也不做查重、腾讯文档登记、标题优化。它只做一件最重要的事：

> 在你已经打开并登录好的 AdsPower / Temu 商品详情页里，自动找到主图候选区域，提取英文标题，截图保存，并用标题命名。

---

## 你需要先做什么

1. 打开零点云 VPN。
2. 打开 AdsPower。
3. 打开已经登录好的 Temu 页面。
4. 进入一个商品详情页。
5. 确认页面是英文界面。
6. 双击本项目里的 `run.bat`。

---

## 最简单运行方式

把仓库下载到本地后，直接双击：

```bat
run.bat
```

第一次运行会自动创建 `.venv` 并安装依赖。

如果自动安装失败，手动执行：

```bat
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe -m src.main
```

---

## 当前版本怎么用

1. 双击 `run.bat`。
2. 在窗口里填写或确认 AdsPower profile_id。
3. 点击“连接 AdsPower”。
4. 点击“识别当前商品页”。
5. 检查标题框里的英文标题。
6. 检查候选图片编号。
7. 不合适就点“下一张候选图”。
8. 合适就点“保存截图”。

截图会保存到：

```text
D:\Temu截图\截图结果\当天日期\
```

登记表会保存到：

```text
D:\Temu截图\登记\截图进度.xlsx
```

---

## 文件命名规则

截图文件名来自商品详情页右侧标题区域的英文标题。

程序会做最低限度清洗：

- 删除 Windows 不允许的字符：`\ / : * ? " < > |`
- 去掉多余空格和换行
- 文件名过长会截断
- 重名会自动追加 `_001`、`_002`

注意：当前版本会尽力自动提取标题，但 Temu 页面结构可能变化。如果自动提取不准，可以直接在窗口标题框里手动修改，再保存截图。

---

## 当前版本边界

v0.1 先不做这些：

- 不自动查重
- 不自动登记腾讯文档
- 不自动优化标题
- 不自动破解验证码
- 不并发打开页面
- 不下载图片 URL
- 不做后台接口抓取

遇到验证码、登录异常、页面异常时，你手动处理，然后重新点击识别。

## 配置文件

配置文件是：

```text
config.json
```

常用字段：

```json
{
  "adspower_api": "http://local.adspower.com:50325",
  "profile_id": "",
  "output_root": "D:/Temu截图/截图结果",
  "registry_path": "D:/Temu截图/登记/截图进度.xlsx"
}
```

如果不知道 profile_id，可以先打开程序点击“列出环境”，然后复制需要用的环境 ID。
