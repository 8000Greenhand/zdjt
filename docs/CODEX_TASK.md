# 给 Codex 的任务说明

当前仓库目标：Temu 前台截图助手。

第一版 v0.1 已经实现：

```text
连接 AdsPower
识别当前商品详情页
提取英文标题
寻找页面可见主图候选
截图保存
用标题命名
写入本地 Excel
```

请不要直接把它改成后台爬虫，不要下载图片 URL，不要并发请求。

---

## 必须遵守的业务规则

1. 用户已经在 AdsPower 里登录 Temu。
2. 第一阶段只做前台截图，不做图片下载。
3. 商品页面必须是英文界面。
4. 文件名来自商品标题区域可见的前 2 行英文。
5. 截图只要清晰正面主图，不要侧面图、局部图、三连图、带大留白图。
6. 遇到验证码、登录异常、风控验证，暂停交给用户处理，不要自动绕过。
7. 不做并发。
8. 查重放后续版本。

---

## 推荐开发顺序

### v0.2

从当前搜索结果页，自动打开第一个商品，然后进入店铺。

验收：能从用户已打开的搜索页进入一个店铺。

### v0.3

在店铺页按销量排序。

验收：能点击排序按钮并确认列表变化。

### v0.4

从店铺列表打开销量 ≥5 的商品。

验收：能跳过销量不足 5 的商品。

### v0.5

主图候选加入视觉评分。

验收：明显小图、拼接图、过多留白图能被降权。

### v0.6

接入以图搜图查重。

验收：截图后先进入临时目录，查重通过才进入合格目录。
